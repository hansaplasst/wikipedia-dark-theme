# Wikipedia Dark Theme

A userscript for Wikipedia that automatically:

1. Selects the **Dark** theme option.
2. Hides the **Appearance** panel.

The script is designed for use with Chrome based browsers with the [Tampermonkey](https://www.tampermonkey.net/) or [Greasemonkey](https://www.greasespot.net/) plugin.

## Features

- Works on all Wikipedia language domains.
- Selects the `Dark` theme setting.
- Hides the Appearance panel after the theme has been selected.
